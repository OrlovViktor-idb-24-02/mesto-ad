# Mesto — работа с сервером

Адаптивная страница для обмена фотографиями на JavaScript и Vite. Заключительное задание — вариант 1: статистика карточек.

[Опубликованный проект](https://orlovviktor-idb-24-02.github.io/mesto-pages/) · [Исходники для проверки](https://github.com/OrlovViktor-idb-24-02/mesto-ad), ветка main.

## Возможности

- Профиль и карточки загружаются автоматически через Promise.all. Посетителю не нужно вводить токен или выбирать группу.
- Редактирование имени, описания и аватара, создание карточек и подтверждение удаления собственных карточек.
- Лайки и счётчик обновляются только после успешного ответа сервера. Повторное нажатие блокируется на время запроса в модуле card.js.
- Просмотр фотографии и статистики карточки. Для статистики запрашивается актуальный список с сервера; она не изменяет счётчик лайков на карточке.
- Дата создания, автор, число лайков и список пользователей выводятся через HTML-шаблоны.
- Проверка форм, сообщения об ошибках, состояния загрузки и защита от повторной отправки.
- Закрытие модальных окон кнопкой, по Escape и клику на фон. Модуль modal.js отвечает за базовое открытие и закрытие окон.
- Адаптивность от 320 px, локальные файлы шрифта Inter.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
```

Когорта и учебный токен уже указаны в src/scripts/components/api.js. Дополнительная настройка не требуется:

```sh
npm run dev
npm run check
npm run build:public
npm run preview
```

dist исключён из Git. Формы используют стандартные сообщения браузера и ограничения полей в HTML.

## Публикация

Сборка находится в dist, base './' позволяет разместить её в подпапке GitHub Pages.

Для локальной публикации настроенной сборки:

```sh
npm run deploy
```

Команда отправляет dist в main репозитория mesto-pages. В его настройках Pages используются main и / (root).

Автоматическая сборка mesto-ad использует настройки из api.js. Секреты PUBLIC_PAGES_TOKEN и PUBLIC_PAGES_REPO задают публикацию в отдельный публичный репозиторий. До настройки этих секретов автоматическая публикация недоступна.

## Структура

- src/scripts/index.js — запросы, обработчики и отрисовка страницы.
- src/scripts/components/api.js — настройки API, запросы и проверка ответов.
- src/scripts/components/card.js — разметка карточки, лайки и блокировка кнопок.
- src/scripts/components/modal.js — открытие и закрытие модальных окон.
- src/scripts/components/validation.js — проверка форм.
- src/styles/index.css — стили и адаптивная вёрстка.
